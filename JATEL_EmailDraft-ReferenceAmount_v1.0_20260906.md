**Status:** DRAFT. **Not sent.** Send from `hello@benchandbloom.com`.
**Why it matters:** the answer sets the declared serving size and therefore every value in the

**To:** food-aliment@hc-sc.gc.ca
**Subject:** Reference amount for a flavouring syrup: U.14 or U.15?

```
Hello,

I am seeking confirmation of the correct reference amount for a product, so that
I declare the right serving of stated size in its Nutrition Facts table.

The product is a lavender flavouring syrup, 250 mL, in a glass bottle, for sale
in Canada with a bilingual label. It is stirred into cocktails, sparkling wine,
lemonade, coffee and warm milk. It is not a topping and is not intended to be
poured over food.

Two entries in the Table of Reference Amounts appear to be candidates, as I read
them:

  U.14  syrups used as toppings                          60 mL
  U.15  syrups used as ingredients, such as corn syrup,
        agave syrup and flavoured syrups for milk         30 mL

I believe U.15 applies, because the product is used as an ingredient in a
beverage rather than as a topping, and because the U.15 description expressly
includes flavoured syrups for milk, which is one of its principal uses.

Can you confirm which reference amount is correct for this product?

For context, the answer does not change whether the front-of-package "High in
sugars / Élevé en sucres" symbol is required, which it is under either entry. It
determines the declared serving size and therefore the values in the Nutrition
Facts table.
```

## Notes

**One question, asked once.** The same discipline as the symbol request: a single narrow question
gets a fast answer, a bundle invites a slow one. Everything else regulatory stays with the CFIA
Industry Labelling Tool session.

**The U.14/U.15 wording above is a paraphrase**, marked as such in the email with "as I read them".
**[Moderate confidence]** — the item numbers and descriptions came via a prior session and I have not
opened the Table myself. Asking them to confirm makes any error in my paraphrase harmless.

**What changes if the answer is U.14.** Serving becomes 60 mL, and per-serving values roughly double
from the current 30 mL basis: about 200 calories and 51 g sugars at 51% DV. The label and the
`/nutrition` page both have to be rebuilt on the new basis. That is why this is worth asking before
artwork is drawn, not after.
